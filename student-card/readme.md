Student Card System
About the Project

Student Card System is a React-based web application developed using reusable components. It helps users view and manage student information through individual student profile cards.

Project Objectives
Display student details in card format.
Create reusable React components.
Add new student information.
Search students by name or roll number.
Delete student records.
Develop a responsive user interface.

Installation

Clone the repository:

bash
git clone YOUR_GITHUB_REPOSITORY_URL


Move into the project folder:

bash
cd student-card


Install dependencies:

bash
npm install


Run the application:

bash
npm run dev

Project Purpose

This project is developed to understand React reusable components, props, state management, and basic student information management.
